# Tesi — bozza capitoli

Cartella di lavoro per il testo della tesi (Markdown). Il codice e i numeri ufficiali restano in `docs/PROGETTO.md`, `notebooks/` e `data/eda_cache/`.

## Come usarla

| File | Ruolo |
|------|--------|
| [00-titolo-e-abstract.md](00-titolo-e-abstract.md) | Titolo provvisorio, sottotitolo, abstract IT/EN (bozza) |
| [01-draft-struttura.md](01-draft-struttura.md) | Indice generale, obiettivi, filo narrativo |
| [capitoli/](capitoli/) | Un file per capitolo: obiettivo, outline, note, TODO |

Quando un capitolo è maturo, si può esportare in Word/LaTeX del ateneo; qui teniamo solo contenuto e struttura.
